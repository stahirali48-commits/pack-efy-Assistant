# Changes made for the Module 08 submission

These are targeted changes to the supplied project. The original knowledge documents, answer-generation logic, and existing 20-question results were preserved.

1. **Streamlit evidence display (`app.py`)** - added source filename/version/status, a short supporting excerpt, and an expandable section for retrieved chunks under each assistant answer. Improved the technical error message to mention API key, internet, model access, and quota.
2. **Experiment configuration (`src/build_index.py`, `src/retriever.py`)** - added environment overrides for chunk size, overlap, and Chroma database path. The original defaults remain 180 words and 35 words of overlap, using the original `chroma_db` folder.
3. **Reproducible retrieval experiment (`tests/run_retrieval_experiment.py`)** - added a six-question comparison at k=1/3/5 and a three-question subset for the changed chunk configuration. The script records retrieved sources, evidence excerpts, irrelevant-source candidates, and generated answers. Manual correctness is deliberately left blank for review.
4. **Test rerun helper (`tests/run_tests.py`)** - added a runner for the existing 20-question test set. New reruns are marked REVIEW until a person checks the answer and supporting evidence; it does not overwrite the recorded `test_results.csv`.
5. **Submission materials** - added `.env.example`, `.gitignore`, README, a two-page report (Markdown and PDF), demo recording guide, and this change log.

## Preserved

- The five supplied knowledge documents.
- The original Groq-based answerer and system prompt.
- The original Chroma retrieval approach and default chunk settings.
- The recorded 20-question result table (20 PASS, 0 FAIL); its notes still call for manual evidence review.

## Not fabricated

The uploaded RAR did not include a completed six-question k/changed-chunk experiment output or a demo video link. The experiment runner and recording guide are supplied, but these two evidence items must be generated by running the project and recording the screen before final LMS upload.
